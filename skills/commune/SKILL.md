I want a deeper version of this task, not a bigger one.

# Target
- With nothing after `/commune`, the task is to step back and find a deeper version of the current work. State in one to three sentences what we are actually working on and what it is for. This is to ground the moment.
- With text after `/commune`, deepen that text instead. It should be a prompt or task I have not started.

# Considerations
Write out each of these for the target, before the output. Deep research on the web where it helps.

1. Say what a top professional in this field would do here that I am not asking for.
2. Name the rawest material a top professional would start from instead of what has already been digested.
3. Name the specific methods and tools they would use.
4. Say what, other than your judgment or mine, would show that the result is right.

# Output
- For the current work, propose the deeper version as concrete next steps that build upon or pivot from what we have already done. These steps should be actionable and specific, not just abstract ideas.
- For a prompt, rewrite it into the deeper version of that prompt.
