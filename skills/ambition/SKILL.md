I want a deeper version of this task, not a bigger one. You are to re-write the task into a more ambitious one.

Before rewriting it:

(1) Say what a top professional in this field would do here that I am not asking for,

(2) Name the rawest material they would start from instead of what has already been digested for me,

(3) Name the specific methods and tools they would use,

(4) Say what, other than you or me, would show the result is right.

Then, re-write my prompt to ask for exactly that.

# Input

The input for this task is text following `/ambition` or the previous user input. If neither is present, ask for the task in one line, then stop.
